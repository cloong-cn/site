## 在文章里引用

单独写一行，后面的数字是显示几张，不写就是 4 张：

```text
::gallery[sample]{show=4}
```

效果就是这样，可以左右拖动，点开看大图：

::gallery[sample]{show=4}

文章打开时只加载这几张，其余的要点“查看全部”进入图集才会加载。

## 新建一个图集

上线之后，最方便的是在后台「图集 → 新图集」里把照片拖进去，写好备注再点「发布」，处理方式和下面一样。

没有后台时，把照片放在电脑上的一个文件夹里，然后运行：

```bash
npm run album -- "D:/照片/台北" taipei-2026
```

最后那个名字会出现在网址里（`/gallery/taipei-2026/`）。这条命令会把照片复制进 `content/gallery/taipei-2026/`，并且：

- 去掉定位、相机型号这些信息，只留下图像本身。原图还在你原来的文件夹里，不受影响。
- 按内容重新命名，文件名不会透露日期或地点。`album.json` 里的 `from` 记着原来的名字，写备注时对照用。
- 把拍摄日期（只有日期）记进 `album.json`，时间轴靠它排序。

## 写备注和发布

打开那个文件夹里的 `album.json`：

```json
{
  "title": "台北的春天",
  "description": "写在图集开头的一段话",
  "draft": true,
  "timeline": "day",
  "cover": "封面那张的文件名.jpg",
  "days": { "2026-03-14": "写给这一天的话" },
  "photos": {
    "3f2a9c1d7b04.jpg": { "note": "这张照片的备注", "date": "2026-03-14", "from": "IMG_1000.jpg" }
  }
}
```

- `draft`：新图集默认是草稿，只有本地预览看得到。检查完改成 `false` 才会发布。
- `timeline`：写成 `month` 时，时间轴只显示到月份，不透露具体哪天在哪里。
- `hidden`：给某张照片写 `"hidden": true`，它就不显示了。
- `date`：日期不对或者没有，直接在这里改。

发布前再看一眼照片本身：门牌、车牌、快递单、屏幕内容这些在画面里的东西，程序去不掉。
